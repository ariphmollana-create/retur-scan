Cara Upload ke GitHub Pages

  1. Di GitHub, buat repo baru misal retur-scan, Public.
  2. Upload file ini sebagai index.html (Add file → Upload files).
  3. Settings → Pages → Branch: main, Folder: / (root) → Save.
  4. Buka https://username-kamu.github.io/retur-scan/ di Chrome HP → izinkan kamera.
  5. Kenapa harus GitHub? Karena GitHub Pages itu HTTPS. Kamera HP hanya boleh jalan di HTTPS + dibuka langsung di tab Chrome, bukan file:// dan bukan di dalam chat / iframe.

Catatan: versi GitHub ini simpan data di HP (localStorage), bukan database server. Jadi kalau ganti HP, data tidak ikut. Untuk kerja harian, paste di kolom Barcode tetap paling cepat.
